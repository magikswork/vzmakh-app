# Приложение школы «Взмах» (Москва)

Контекст для Claude Code. Отвечай Лео по-русски, простым языком: он не программист.

## Что это
Одна ссылка, закреплённая в чате в Максе: https://magikswork.github.io/vzmakh-app/
Разделы: Расписание (с заменами), Домашка, Запросы между учителями (фото, статусы, ответы), Ссылки.
Пользователи: ученики и родители (только смотрят, без входа) и учителя (входят по личному коду, пишут).
Почти все открывают с телефона. Mobile first, но на компьютере тоже должно быть удобно.

## Как устроено
- `index.html` + `assets/` — статический сайт на GitHub Pages (ветка `main`, корень). Без сборки, ES-модули.
  - `app.js` — каркас: шапка, нижнее меню, маршруты (`#raspisanie`, `#dz`, `#zaprosy`, `#zaprosy/<id>`, `#ssylki`), вход, загрузка данных.
  - `views/*.js` — разделы. `data.js` — вычисления по расписанию. `ui.js` — общие элементы (панель, чипы, выбор фото). `util.js` — даты, хранение, иконки.
  - `api.js` — сервер; если `config.js → API_URL` пустой, работает `demo.js` (примеры в памяти, баннер «Демо-режим»).
- `backend/Code.gs` — Google Apps Script, привязанный к таблице «Взмах · данные приложения» (id `17k9clPYOOBWt3sJDsHNvCZELBD-i9Z32UQOccdrZdLg`).
  - GET `?action=public` → расписание, звонки, замены, ДЗ, список учителей (без email и кодов).
  - POST (текстовое тело JSON, без заголовков — чтобы не было CORS-preflight) `{action, code, ...}`: `login`, `hw.save`, `hw.delete`, `sub.save`, `sub.delete` (только роль «админ»), `req.list`, `req.create`, `req.comment`.
  - Вход: личный код учителя из вкладки «Учителя» (8 символов). Код хранится в localStorage.
  - Фото: base64 → папка на Диске «Взмах · фото из приложения», доступ по ссылке; показываются через `drive.google.com/thumbnail?id=`.
  - Письма о новых запросах и ответах — MailApp на email учителя.
  - После правки Code.gs Лео должен сделать «Новая версия» развертывания (docs/SETUP.md, шаг 5) — напоминай.
- Ссылки читаются из отдельной таблицы `1UY_XcfzF1YTbd897pu5wK3SRHbOopWxKYMN85TjFGUg` (gviz JSONP), той же, что у magikswork.github.io/vzmakh-links.

## Правила
- Хостинг и сервисы должны открываться в России без VPN: GitHub Pages и Google — да; Vercel, Firebase — нет.
- 152-ФЗ: не хранить ФИО, оценки и контакты учеников. ДЗ и расписание привязаны к классу.
- Дизайн «Взмах»: оранжевый #E8731A, красный #CF3428, синий #2D5C93, фон-тетрадь в клетку, шрифты Unbounded / Golos Text / Caveat, светлая и тёмная темы, всё через токены в `styles.css`. Без горизонтального скролла на 375px, зоны нажатия от 40px.
- Тексты интерфейса — короткие, по-человечески, без канцелярита.
- Перед пушем проверяй страницы в Playwright (демо-режим работает без сервера): `python3 -m http.server` и скриншоты 400px и 1200px, светлая и тёмная тема.
