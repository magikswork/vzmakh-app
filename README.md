# Взмах · Москва

Приложение частной школы «Взмах» (московский филиал): расписание с заменами, домашние задания, запросы между учителями и рабочие ссылки — по одной ссылке.

**Открыть:** https://magikswork.github.io/vzmakh-app/

- Ученики и родители: выбирают класс и смотрят расписание и ДЗ, входить не нужно.
- Учителя: входят по личному коду, задают ДЗ, отправляют коллегам запросы с фото и отвечают на них.
- Администратор: вносит замены в расписание прямо из приложения.

Данные хранятся в Google Таблице школы, сервер — Google Apps Script. Как подключить: [docs/SETUP.md](docs/SETUP.md).
